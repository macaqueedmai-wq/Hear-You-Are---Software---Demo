# MVP 驗收記錄

版本：v0.2.0　日期：2026-10-13（香港）　整理：Yonghan（with Codex）

## 一、五項功能

- **前端 UI**：React／TypeScript／Vite，實際改造 MoodHaven MIT 元件，柔和淺紫色、每日卡片首頁。四頁導覽、日期選擇、來源側欄、偏好、空白／處理／失敗／完成狀態均可操作。TypeScript 與生產建置通過；npm 生產依賴審查 0 漏洞。
- **錄音轉寫**：實際執行 faster-whisper＋large-v3-turbo，本機音訊解碼、VAD、英文轉寫及時間戳。保留錄音原件，只對工作副本處理；未確認說話者不自動當成用戶。上傳、重試、原音回放及 Range 回應已驗證。
- **記憶 Infra**：五層為原始證據、原子記憶、整合版本、有效檢索及治理。SQLite 保存來源、事件／偏好、版本、卡片依賴及接收狀態。修改保留原話；刪除／過期使關聯輸出失效；重複音訊不增加證據；未知時間不拿匯入時間代替。
- **每日卡片總結**：心情、社交及重要片刻，以繁體中文歸納明確表述，保留英文來源。主體確認與理解核實分開；各卡主動請核實或修改，確認核對完整來源版本與摘要 token。
- **主動式 AI**：主動核實理解，再以已核實的過往與當前記憶作睡眠跟進、社交鼓勵及情緒支持。提醒、建議、安慰、虛構預警各有前置條件；免打擾、頻率及來源重查同時適用。零類、多類未決或來源失效保持不輸出。

## 二、本機瀏覽器實際操作

以新的 `data/verification-ui/` 隔離驗收資料；只使用虛構逐字稿、合成英文錄音和虛構資料格式，不使用私人音訊或真實諮詢紀錄。

1. 載入每日卡片演示，三類卡片即顯示繁體摘要與核實問題。逐卡確認後狀態改為「理解已核實」。
2. 跨日睡眠情境展示過往兩天與今天的已核實來源、休息建議與「是否設定睡覺提醒」。用戶選擇未來香港時間並點「允許並設定提醒」後才建立事項，舊建議取消，未到期不提醒。
3. 偏好中匯入 `docs/dataset-example.jsonl`，三項資料保存成功；可看來源與授權，所有項目顯示待專業審核、未訓練、未啟用。
4. 上傳 `synthetic-english.wav`（19.001 秒），選定原始時間 `2026-10-13T10:30:00+08:00`。真實 GPU 轉寫成功：載入 2.241 秒、推理 0.760 秒、合計 3.001 秒；四段英文原話及原始時間戳可見。逐片段確認屬本人後，卡片保持「理解待核實」。
5. 來源修改、版本衝突與原音按時間回放也已操作；HTTP 測試另驗證刪除傳播及轉寫中刪除後不復活來源。

詳細轉寫環境、英文原文、CPU／GPU及暖機結果見 [ASR 驗證](ASR-VERIFICATION.md)。這是短合成語音的功能驗證，不代表所有口音、噪音或多人對話的準確率。

## 三、自動驗證

完整 pytest **124 項測試**、TypeScript／Vite 生產建置及 Python 套件一致性檢查通過。測試涵蓋：

- 主體未確認／理解未核實／歷史日期／來源集合與版本衝突。
- 歷史與當前支持、不同睡眠日期、明確睡眠不足、否定句不誤判、用戶授權後才設定提醒。
- 到期提醒、四類條件、零類／多類、偏好、免打擾、延後、頻率及展示前再次檢查。
- 去重、保留期限、修改／刪除／模型摘要後的失效，背景轉寫與刪除的競態。
- 無效音訊、檔案及時長限制、原音 Range 206、未知 API 404、外部文字模型未授權阻擋。
- 資料集必填欄位、明確授權／去識別、UTF-8、JSON 嚴格驗證、上限、併發去重、原子失敗及刪除。

ASR 單元測試使用轉寫替身；上文及獨立 ASR 記錄才是真正模型執行的證據。LLM 格式及版本測試使用回應替身，本次沒有呼叫外部 LLM。

## 四、目前限制

預設文字摘要及主動支持使用本機規則與模板，對未知語句會保留證據不足提示；可選文字模型接口已提供，尚未設定服務。自動語義衝突合併、多說話者身份辨識、OS 背景通知與重複鬧鐘未實作。

警示只作清楚標示的虛構流程演示；沒有臨床疾病診斷或真實心理危機判斷。專業資料集只提供後期入口，專業審核、後訓練及專業評估尚未啟用。
